# Security Policy

This is research software. It must not be used in patient care.

## Reporting a problem

**Do not open a public issue** for a security flaw, exposed credential, or anything that looks like patient or restricted data.

Use GitHub's private vulnerability reporting (Security tab, "Report a vulnerability"). If it is not available, contact the repository owner through their GitHub profile and share no sensitive details until a private channel is agreed.

Please include what you found, where, and how to reproduce it. Do not download, copy or share the data.

## What we do

1. Acknowledge the report as soon as we can.
2. Contain the problem: make private, revoke credentials, remove data.
3. Notify any data owner or authority as required.
4. Fix it and record what happened.

## Scope

Code and documents in this repository. Data and third-party services have their own processes. If you find identifying information in a PhysioNet dataset, report it to PhysioNet.
