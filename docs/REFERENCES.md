# References

The other documents cite these by ID, for example [R4]. Every DOI was resolved against Crossref on 2026-11-06, and every arXiv ID against the arXiv API on the same date. `tools/check_citations.py` repeats the DOI check.

**Evidence labels used across this repository**

| Label | Meaning |
|---|---|
| **Verified** | Read at the primary source on 2026-11-06: dataset page, statute, licence, or the paper's own abstract. |
| **Secondary** | Reported by a law firm, a news outlet or a third party. The primary text was not read. |
| **Unverified** | Could not be confirmed, or is an assumption. Do not rely on it. |
